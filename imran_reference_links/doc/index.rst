Reference Links User Guide
==========================

1. Install Reference Links from Apps on a compatible Odoo 19 server.
2. Open Reference Links > My Links > New.
3. Enter a title and full http:// or https:// web address. Do not include
   passwords or login credentials in a bookmark.
4. Choose Reference, Learning or Tool. Add optional notes and save.
5. Click Open Link to visit the website in a new browser tab.
6. Click Add Favourite. Favourites appear first in the list. Remove Favourite
   reverses it. Filters > Favourites shows only your favourites.
7. Search text in titles, addresses and notes. Group By > Category groups links.
8. Use Actions > Archive to hide an old link. Filters > Archived shows archived
   records; Actions > Unarchive restores them.

Test by creating two fictional bookmark records, favouriting one, filtering
the list, opening one link and archiving/restoring a record.

Bookmarks belong to their creator and allowed companies. Superuser access
retains normal Odoo behavior. There is no link sharing, automatic checking,
preview generation or browser synchronization. The server does not fetch
the saved addresses; opening a link visits that website in your browser.
