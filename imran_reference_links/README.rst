Reference Links
===============

A free Odoo 19 app for private personal bookmarks.

Features
--------
* Save a title, web address, category and notes.
* Organize links as Reference, Learning or Tool.
* Mark favourites to show them first.
* Search titles, addresses and notes. Filter favourites or group by category.
* Open saved http/https links in a new browser tab.
* Archive and restore older links.
* Each internal user sees their own bookmarks in allowed companies.

Install and use
---------------
Place imran_reference_links in an Odoo addons directory, restart Odoo, update
the Apps list and install Reference Links. Open Reference Links > My Links > New.
Enter a title and a full http:// or https:// address. Choose a category and save.
Use Open Link or Add Favourite.

Scope
-----
Requires only base. Supports self-hosted Odoo 19 Community/Enterprise and
Odoo.sh. Standard Odoo Online cannot load this Python addon. No shared
bookmarks, URL previews, automatic link checks, browser synchronization or
external integrations are included. The server does not fetch saved URLs.
Opening a bookmark visits its website in your browser. Odoo superuser
administration retains normal access.
